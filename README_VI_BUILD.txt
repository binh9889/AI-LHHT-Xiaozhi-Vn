AI-LHHT Xiaozhi Android 2.2.0 - Bản tiếng Việt

BUILD NHANH:
1) Đẩy source lên GitHub branch main.
2) Actions -> Build AI-LHHT Vietnamese APK.
3) Run workflow -> main.
4) Tải artifact AI-LHHT-v2.2.0-VI.
5) Giải nén -> AI-LHHT-v2.2.0-VI.apk.

KẾT NỐI XIAOZHI CHÍNH THỨC:
- Cài đặt -> Xiaozhi -> Kết nối Xiaozhi chính thức.
- Bấm Lấy cấu hình / mã liên kết.
- Nếu server trả activation.code, nhập 6 số tại xiaozhi.me -> Robot -> Thiết bị.
- Liên kết xong quay lại bấm kiểm tra lại để nhận WebSocket URL/token.

LƯU Ý QUAN TRỌNG:
Android dùng Activation-Version=1. Không giả Serial-Number/HMAC eFuse của ESP32.
